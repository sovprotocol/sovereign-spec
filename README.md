# Project SOVEREIGN

**Infrastructure for art and autonomous agents.** Quantum-proof identity, payments, provenance, and privacy. Built to survive Q-Day.

## What We Build

| Protocol | Purpose | Status |
|----------|---------|--------|
| **SOV-ID** | Hybrid PQ identity (Ed25519 + SPHINCS+) | 13/13 tests |
| **SOV-PAY** | x402 quantum-safe micropayments | 3/3 tests |
| **SOV-REP** | PQ-signed verifiable reputation | 3/3 tests |
| **SOV-VAULT** | Art provenance & curator agent | Concept |
| **Typhoon Cash** | zk-STARK privacy mixer for agents | Whitepaper |
